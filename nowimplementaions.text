1. SYSTEM ARCHITECTURE
------------------------------------------------------------
Campus OS is a digital operating layer for modern colleges, connecting students, faculty, academic resources, projects, events, and campus administration.

Core Architecture:
- Frontend (`frontend/`): HTML5, CSS3 custom design system, and Vanilla JavaScript.
    * Pages: index.html, auth.html, dashboard.html, notes.html, tasks.html, timetable.html, attendance.html, resources.html
    * Design System: css/base.css, css/components.css, css/animations.css
    * Utilities: js/app.js, js/storage.js, js/auth.js, js/firebase-config.js, js/api.js
- Database & Storage (Firebase): Firebase Web SDK integrated into HTML JS:
    * User Authentication (Login, Register, Passwords)
    * Firestore Database (Saving user profiles, tasks, notes, timetable, attendance)
    * Firebase Storage (File uploads, PDF notes, profile pictures, assignment links)
- Backend (`backend/`): Python FastAPI service handling:
    * Attendance prediction algorithms & smart scheduling
    * AI features (summarizing notes, auto-categorizing resources)
    * REST API endpoints for HTML/JS frontend to fetch data via standard JavaScript fetch() calls


2. COMPLETE MODULE MAP & IMPLEMENTATION SUMMARY
------------------------------------------------------------
[ACADEMIC SUITE]
- Dashboard (`frontend/dashboard.html`)
  * Overview of today's schedule, pending tasks count, average attendance ring, and campus activity feed.
- Notes System (`frontend/notes.html`)
  * Grid and list view toggles, color-coded tags, subject filtering, search, and full CRUD modal.
- Task Board (`frontend/tasks.html`)
  * 3-Column Kanban Board (To Do → In Progress → Done) with priority indicators (High/Medium/Low) and urgency color badges.
- Weekly Timetable (`frontend/timetable.html`)
  * Mon-Sat interactive schedule grid with active day highlighting and click-to-edit slot allocation.
- Attendance Tracker (`frontend/attendance.html`)
  * Per-subject SVG progress rings, 75% safety threshold calculator, and skip-class prediction logic.
- Study Resources (`frontend/resources.html`)
  * Faculty-verified PYQs, lab manuals, lecture notes with search and subject filter.

[COMMUNITY & SERVICES]
- User Auth (`frontend/auth.html`)
  * Login and Registration tabs, demo user login mode, and session storage.
- Local Storage Engine (`frontend/js/storage.js` & `frontend/js/app.js`)
  * Fallback offline data persistence and automatic demo data generator.


3. DEPLOYMENT & EXECUTION
------------------------------------------------------------
- Open `frontend/index.html` or `frontend/dashboard.html` in any web browser.
- Run Python Backend: `python -m uvicorn backend.main:app --port 8000`
- Zero NPM dependencies or build steps required.
